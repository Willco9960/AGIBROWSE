# AGI-BROWSE

AGI-BROWSE is a scaffold for a local browser with a separately privileged agent broker. The accepted boundaries and target platforms are described in [docs/architecture.md](docs/architecture.md); this repository currently contains package scaffolding only. It does not yet include CEF, an MCP server, or working SDK behavior.
